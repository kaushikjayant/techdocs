## About

I design and build documentation automation platforms for semiconductor engineering
teams. Over 16 years, I've moved from authoring individual documents to architecting
the systems that generate them — RTL-driven parameter extraction pipelines, hierarchical
DITA content architectures, AI-assisted chapter generation, and RAG-powered documentation
explorers.

The platform I architected serves 40+ technical authors across five product lines,
compressing SoC Reference Manual generation from 3–4 weeks to under one working day
while eliminating parameter transcription errors entirely.

I work at the intersection of hardware design flows, structured authoring frameworks,
and AI/ML-assisted content generation. My approach is engineering-first: I write the
automation scripts, design the XML content models, architect the databases, and build
the VS Code extensions my teams use daily.
