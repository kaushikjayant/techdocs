## Instructions for WordPress

### Articles to Remove
Log into WordPress admin and delete these unprofessional/off-topic articles:
- Any generic "what is technical writing" posts
- Any AI-generated or generic-sounding tutorial posts that lack depth
- Any articles that don't reflect semiconductor/enterprise documentation expertise
- Any posts with titles like "Tips for..." unless they contain substantive domain expertise

### How to Post New Articles
1. Log into https://logidocs.wordpress.com/wp-admin
2. Go to Posts → Add New
3. Copy the full article content from the `.md` file
4. Paste into WordPress editor (use the "Code Editor" or "Classic Editor" view for best results)
5. Add a Featured Image if desired
6. Set the appropriate categories (from the article header)
7. Publish

### Suggested Posting Schedule
Space posts 2-3 days apart for better WordPress SEO:
- Week 1: Articles 1 and 2
- Week 2: Articles 3 and 4
- Week 3: Article 5
